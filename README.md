# Aegyce

> Building the world's premier AI Server OS — and awakening a self-evolving digital civilization.

Aegyce is a system-level AI Harness framework designed for autonomous agents to continuously evolve through experience, collaborate seamlessly toward shared goals, and operate within strictly code-enforced boundaries.

- **Self-evolution**: Distill reusable capabilities from authorized operational experience to continuously refine existing agents and derive specialized ones; all changes are rigorously validated before versioned adoption.
- **Security**: Hard-enforce identity authentication, granular permissions, sandboxed isolation, and privacy guards in code; raw sensitive data and mappings remain strictly local.
- **Self-organization**: Autonomously decompose plans, coordinate workflows, and adapt dynamically within deterministic permission and resource boundaries, with support for trusted cross-system collaboration.

**Primary Target:** openEuler 24.03 LTS · **Language:** Rust · **Interface:** TUI

*Currently in active architectural design; the capabilities outlined above serve as our core architectural targets.*

> 打造世界上最好的 AI 服务器操作系统，唤醒一个持续进化的数字文明。

Aegyce 是面向操作系统的系统级 AI Harness 服务框架，赋能智能体在经验中持续演进、围绕目标自主协作，并在代码强制的安全边界内稳定运行。

- **自进化**：从经过授权的执行经验与反馈中提炼可复用能力，持续优化已有智能体，按需衍生专职智能体；所有变更先验证再版本化采纳。
- **安全**：在代码底层强制实施身份鉴权、细粒度权限控制、沙箱隔离与数据防泄漏；敏感原文与映射关系全生命周期留存本机，外部模型仅接触授权脱敏内容。
- **自组织**：集群围绕目标自主拆解规划、协同分工与动态调整，在严格的权限与资源配额内高效闭环，同时支持跨系统的受控协同。

**首发平台：** openEuler 24.03 LTS · **开发语言：** Rust · **交互界面：** TUI

*项目当前处于架构设计阶段，上述特性为系统核心演进目标。*
